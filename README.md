# Sourabh Prasad — Portfolio

Personal portfolio built with Next.js 15, Tailwind CSS v4, Framer Motion and MongoDB.

**Live:** <your-vercel-url>

## Features
- Animated landing page with a cursor particle effect
- Projects showcase with live previews
- Contact form saved to MongoDB

## Run locally
```bash
npm install
# create .env.local with MONGODB_URI=...
npm run dev
```
